# PixelScope — краткая подготовка к защите

**Как объяснить устройство программы:** окно PySide6 загружает файл, PIL переводит его в RGB-массив NumPy, OpenCV выполняет обработку, а Qt отображает два изображения рядом. Исходный массив не изменяется: каждый инструмент строит новый результат от оригинала. Метаданные берутся из файла изображения; гистограммы строит Matplotlib.

### Самые вероятные вопросы

**Что такое глубина цвета?** Количество бит на пиксель. Например, в RGB с 8 битами на каждый из трёх каналов получается 24 бита на пиксель и более 16 миллионов кодовых сочетаний.

**Почему значения RGB, HSV, HSL и LAB различаются?** Это разные координаты описания одного и того же цвета. RGB показывает каналы света, HSV/HSL разносит тон и насыщенность, LAB приблизительно согласует координаты с особенностями цветового восприятия. CMYK в PixelScope рассчитывается по простой формуле без профиля принтера.

**Как работает инверсия?** Для 8-битного канала новое значение равно 255 минус старое: чёрный становится белым, красный (255,0,0) — голубым (0,255,255). Применяют формулу независимо к каналам.

**Как получается чёрно-белое изображение?** RGB переводится в один канал интенсивности/яркости, после чего это значение повторяется в трёх каналах ради отображения. Человеческий глаз неодинаково чувствителен к красному, зелёному и синему компонентам.

**Что такое яркость, контраст и насыщенность?** Яркость сдвигает интенсивность каналов, контраст раздвигает значения относительно среднего уровня, насыщенность влияет на удалённость цвета от серого (здесь — через S-канал HSV).

**Линейная и нелинейная коррекция?** Линейная растягивает диапазон значений от минимума до максимума; нелинейная гамма-коррекция меняет полутона степенной функцией.

**Что показывает гистограмма?** Число пикселей каждой интенсивности (и каждого цветового канала). Она показывает распределение значений, но не расположение пикселей.

**Эрозия vs дилатация?** Эрозия уменьшает светлые области и убирает светлый шум; дилатация увеличивает светлые области и может закрывать маленькие разрывы. Их комбинации дают открытие и закрытие.

**Что такое морфологический градиент?** Разность дилатации и эрозии, выделяющая переходы по краям объектов.

**Зачем нужен Otsu?** Метод автоматически находит порог для разделения изображения на два класса интенсивностей. После пороговой обработки морфология работает с бинарной маской.

**Как работает размытие в движении?** Каждый выходной пиксель вычисляется как среднее значений вдоль определённого направления — в PixelScope вдоль диагонали. Это свёртка изображения с направленным ядром.

**Как работает медианный фильтр?** Заменяет интенсивность пикселя медианой значений ближайших соседей. Хорошо убирает импульсный шум «соль и перец».

**Как работает тиснение?** Свёртка с ядром, выделяющим разницу интенсивности по направлению; затем вводят смещение, чтобы получить вид рельефа.

**Что делает повышение резкости?** Свёртка усиливает локальные перепады яркости, вследствие чего границы выглядят чётче. При чрезмерном применении усиливается шум.

**Canny по шагам?** Сглаживание → градиент → подавление немаксимумов → двойной порог → соединение границ по связности (гистерезис).

**Оператор Робертса?** Вычисляет два градиента по диагоналям на маленьких ядрах 2×2 и объединяет их величины. Чувствителен к шуму.

**Harris?** Определяет углы по тому, насколько сильно меняется интенсивность окна при небольшом сдвиге в разных направлениях.

**SIFT?** Находит устойчивые ключевые точки в нескольких масштабах, задаёт им ориентацию и строит градиентные дескрипторы.

**FAST?** Быстрый детектор углов: сравнивает интенсивность центрального пикселя с точками на окружности. Самостоятельного дескриптора FAST не создаёт.

**Почему не SURF?** Методичка разрешает 3 из 4 алгоритмов. Harris, SIFT и FAST доступны в стандартном OpenCV, а SURF часто требует дополнительной сборки.

**Как сравниваются изображения?** Каждое уменьшается до небольшой grayscale-сетки; dHash кодирует, где соседний пиксель ярче другого. Пару с минимальным расстоянием Хэмминга считаем наиболее похожей по этой метрике. Это не распознавание содержания.

**Что такое вычитание фона?** Модель MOG2 оценивает статистику пикселей во времени и выделяет области, отличающиеся от фона. Вторая видеооперация размывает пиксели маски движения.

### Порядок быстрой демонстрации

1. Открыть PNG/JPG; показать размеры, глубину цвета и формат.
2. Кликнуть по пикселю, увидеть шесть моделей.
3. Подвигать яркость, контраст и насыщенность; открыть гистограммы «до/после».
4. Показать erosion/opening, sharpen, Canny и Harris/SIFT.
5. Загрузить 3–10 картинок в Compare; показать найденную пару.
6. Открыть короткое видео с движущимся объектом и переключить режим на размытие.

**Совет:** для защиты держать рядом несколько подготовленных изображений с контрастными углами и короткое видео с неподвижной камерой. Так методы будут выглядеть нагляднее.
